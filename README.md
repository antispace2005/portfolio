# JSON-driven React Portfolio

This project was created with AI assistance and turns structured JSON into a simple personal site.

## What it is

- A Vite + React app
- A portfolio/CV site driven by `src/data/site.json`
- Easy to edit without touching the React components

## What it shows

- Hero section with name, role, summary, and contact links
- About, education, skills, projects, certifications, languages, and contact sections
- Content that can be updated by editing JSON only

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Edit content

Update `src/data/site.json` to change the text, links, and sections shown on the page.
